| **嘈杂的声音** |

|  |  |
| --- | --- |
|  | 辉夜回归演唱会结束后，网络上冒出了一群吐槽香奈美的黑粉。 |
|  | 黑粉们看腻了香奈美公式化的表演，甚至对她甜美系的定位产生了质疑。 |
|  | 那些恶意剪辑过的演唱会的片段，和故意放大的细节图一时间传遍了整个互联网。 |
|  | 一些无良的娱乐媒体为了博取流量，也跟风发布了香奈美走下坡路的通告。 |
|  | 眼看着这一场负面风波来势汹汹…… |
|  | 经纪公司紧急启动了公关预案，试图在一定程度上控制舆论发酵。 |
|  | 同时向艺人团队、企划部、市场部和运营部发起了会议邀请。 |
|  | （香奈美在接到会议邀请后，找我倾诉了一下她的困境。） |
|  | （出于对香奈美的关心，我决定陪她一同参会。） |
|  | 到了会议当天…… |

|  |  |
| --- | --- |
|  | （我提前做好了准备，按照约定的时间赶往了艾顿娱乐公司附近。） |
|  | 香奈美：引航者，我在这里哦！ |
|  | （明明相隔了好一段距离，香奈美却一眼就看到了我。） |
|  | 引航者：（她很早就来了吗？） |
|  | （想到香奈美可能等我很久了，我加快速度朝着她的方向跑过去……） |
|  | 引航者：你等很久了吗？ |
|  | （我气喘吁吁地停下了脚步，看向眼前的少女。） |
|  | 香奈美：欸嘿，听说去见喜欢的人，才会用跑的呢！ |
|  | 香奈美：引航者这是在向我表达些什么吗？ |
|  | 引航者：你的状态不错啊，都能和我打趣了。 |
|  | （我眼前的少女明朗地笑了起来，这一瞬间几乎让我忘了她仍处于舆论漩涡之中。） |
|  | 香奈美：我们稍等一下再进公司哦！ |
|  | （香奈美在我的面前打开了一小盒樱桃味的雪糕。） |
|  | 香奈美：每次开会之前，香奈美都会吃点雪糕。 |
|  | 引航者：（吃雪糕压压惊？） |
|  | （我正猜想着香奈美养成这个习惯的原因……） |
|  | （一个装着雪糕的勺子已经递到了嘴边。） |
|  | 引航者：（一口吃掉。）（一口吃掉。）（浅尝辄止。）（浅尝辄止。） |
|  | （香奈美毫不忌讳地吃完了剩下的雪糕，我的脸却有点儿红了。） |
|  | （香奈美毫不忌讳地吃完了剩下的雪糕，我的脸却有点儿红了。） |
|  | 香奈美：香奈美准备好啦，出发吧！ |
|  | 进入公司…… |
|  | （我跟着香奈美穿过了长长的走廊，抵达了202会议室。） |
|  | 会议室的门紧闭着，但仍有争吵的声音传出来。 |
|  | 香奈美毫不犹豫地推开门，走了进去。 |

|  |  |
| --- | --- |
|  | 工作人员：大家静一静，主角到场了。 |
|  | （会议室的气氛很凝重，连我都感受到了低气压。） |
|  | （会议主持人卡蒂迅速给我和香奈美安排好了座位。） |
|  | 经纪人-卡蒂：既然人都到齐了，那就进入正式环节。 |
|  | 经纪人-卡蒂：但是，事先我得强调一句，艺人团队有持保留意见的权利。 |
|  | （经纪人倒是很有气场。） |
|  | 运营部部长：呵，你说这些话毫无意义吧？ |
|  | 运营部部长：今年，香奈美的演艺活动出现过两个月的中断…… |
|  | 运营部部长：演唱会也只回顾了老作品，这种操作确实太掉以轻心了。 |
|  | 运营部部长：要知道，在娱乐行业从高人气跌落到谷底，只是一瞬间的事情。 |
|  | 经纪人-卡蒂：艺人的身体状况需要疗养，难道不能中断工作吗？！ |
|  | 经纪人-卡蒂：另外，没有任何企划说回归演唱会也要包含新作品。 |
|  | 市场部部长：我提过要给香奈美丰富标签，打破单一化的属性，但是被某人拒绝了。 |
|  | 经纪人-卡蒂：你的辣妹方案只会带来人设崩盘的问题。 |
|  | 企划部部长：让我说！偶像都是有生命周期的，需要研究一下香奈美的红利周期。 |
|  | 企划部部长：除此之外，我正在做新的女团企划。 |
|  | 企划部部长：希望能靠着香奈美的曝光度帮公司捧一捧新人。 |
|  | 引航者：（竟然还有这种奇葩操作？） |
|  | 经纪人-卡蒂：我问你要不到资源，原来你是在暗中另起炉灶了！ |
|  | 企划部部长：没办法，企划部在你那里施展不出才华。 |
|  | 经纪人-卡蒂：到目前为止，艺人团队哪点没配合你们了？ |
|  | 经纪人-卡蒂：倒是你们之前老是忽视香奈美创作的歌曲小样，打击我们艺人的热情…… |
|  | 引航者：（香奈美也会写歌吗？） |
|  | 企划部部长：我给你们接洽的都是金牌音乐制作人！乐坛里的顶尖人物！ |
|  | 企划部部长：他们的作品是有市场认可度的，怎么能和艺人写着玩的歌相提并论。 |
|  | 经纪人-卡蒂：你听都没听，怎么能下结论呢？！ |
|  | 会议室里的争吵声更加响亮了…… |
|  | 比起解决问题，他们更想要趁艺人团队处于劣势，来抢夺权力…… |
|  | 香奈美始终沉默着，直到会议宣布结束的那一刻…… |
|  | 香奈美抬起低垂着的头，就像是谢幕一般露出了灿烂的笑容。 |
|  | 香奈美：辛苦大家了，香奈美会好好加油的！ |
|  | 人们只是随意地点了点头，接二连三地离开了会议室。 |
|  | 卡蒂因为要和企划部部长继续探讨一些问题，也先行离开了。 |
|  | （宽敞的会议室，只剩下了我和香奈美。） |
|  | 引航者：部门之间的唇枪舌战，给了我一点小震撼。 |
|  | （我故意用很夸张的语气说话，想要让香奈美好受一点。） |
|  | 香奈美：引航者见过不少大场面吧？ |
|  | 香奈美：香奈美可不觉得这里会吓到你哦！ |
|  | 香奈美的笑容里藏着一丝苦涩，眼神中透露着疲惫。 |
|  | 但她却极力地掩饰着真实情绪，尽量表现得若无其事。 |
|  | 香奈美：引航者看我的表情怪怪的…… |
|  | 香奈美：其实，你真的不用太担心香奈美哦。 |
|  | 香奈美：这种强度的会议我开过很多次了，抗压能力早就练出来啦！ |
|  | 香奈美：更何况我还用吃雪糕的行为做了心理补偿呢！ |
|  | （她说得越多，我越觉得心疼。） |
|  | 引航者：（摸摸头。）（摸摸头。）（抱住。）（抱住。） |
|  | 香奈美：引航者…… |
|  | 香奈美：引航者…… |
|  | 香奈美：是在安慰香奈美吗？ |
|  | （香奈美在真正受到关心的时候，更多地表现出了懵懂和生疏。） |
|  | （她究竟经历过一些什么呢？） |
|  | （我想要更多地了解香奈美。） |
