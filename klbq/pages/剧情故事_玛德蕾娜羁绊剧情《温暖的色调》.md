|  | （肚子兀自抗议地叫了起来。） |  |
|  | 引航者：（……） |  |
|  | （起身去接咖啡。） |  |
|  | （星芒咖啡已经迭代升级到ver.36.9.87.66，口感和味道得到了极大程度地改善。） |  |
|  | （尽管还是微妙地保留了金枪鱼这样的奇怪原料……） |  |
|  | （为了能稍微缓解饥饿，还是打算一饮而尽。） |  |
|  | 引航者：（……？） |  |
|  | （接通电话。） |  |
|  | 迷糊而可爱的声音：引航者~好久不见了呀！ |  |
|  | （电话那头传来了玛德蕾娜熟悉的声音。） |  |
|  | （似乎和平时的语气相比，略显羞涩。） |  |
|  | 玛德蕾娜：那个……嘿嘿，上次和你说过的，利里家的艺术交流会…… |  |
|  | 玛德蕾娜：不必紧张啦，不是什么正式严肃的场合，就是想邀请你来我们家，和我、还有我的父母一起吃个晚餐…… |  |
|  | 玛德蕾娜：爸爸妈妈听说了你的事迹以后，非常想认识你呢！ |  |
|  | 玛德蕾娜：呃，我也知道你很忙啦，所以我尽量挑了一个休息的时间，还特地找星绘小姐确认过你近期的日程安排。 |  |
|  | 玛德蕾娜：你怎么不说话啊……？果然不行吗？ |  |
|  | （玛德蕾娜的声音低落了下去……） |  |
|  | 引航者：并非如此…… |  |
|  | （饥饿的肚子再次发出了抗议。） |  |
|  | 玛德蕾娜：噗……我明白啦！那今晚的晚餐你可更不能错过了喔！ |  |
|  | 玛德蕾娜：为了展示《田野物语Ⅳ》，也为了欢迎你来我们家做客，我们特地准备了一整桌子好吃的。 |  |
|  | 玛德蕾娜：地址在……这个位置，你到的时候跟我说一声，我来楼下接你~ |  |
|  | （在一阵欢声笑语中，玛德蕾娜挂断了电话。） |  |
|  | （对接下来的晚餐充满了期待。） |  |
|  | （只是对还要和利里家的长辈们一起用晚餐这件事……感到了一丝丝紧张。） |  |
|  | （前往玛德蕾娜父母家。） |  |

|  | （艾顿城艺芸区——） |  |
|  | （在小区门口，远远地就看到一个穿着衣装鲜亮、扎着马尾辫的女孩子傻笑着朝我挥手。） |  |
|  | 玛德蕾娜：引、航、者——！ |  |
|  | 玛德蕾娜：这里、这里！ |  |
|  | （她雀跃着欢迎我的到来，就像迎接自己的家人一样……） |  |
|  | （跟随着玛德蕾娜小鹿似的欢快步伐走上楼，一路上很担心她会摔倒。） |  |
|  | （打开屋门，晚宴上食物的香气扑鼻而来。） |  |
|  | （虽然都是普通的家常菜，但明亮的烛光，还有主人的笑容，都在传递着独属于这个家庭的温馨。） |  |
|  | 玛德蕾娜：爸爸、妈妈，这就是我之前跟你们提起过的引航者，我的金牌艺术顾问！ |  |
|  | 玛德蕾娜：我和引航者一起化解了不少危机和麻烦，还顺手创造出了了不起的艺术成果。 |  |
|  | 玛德蕾娜：引航者，你还站着做什么？快点坐下来用餐吧。 |  |
|  | （已经坐下的玛德蕾娜向我指了指距离她最近的位置。） |  |
|  | （坐在玛德蕾娜身边。） |  |
|  | 玛德蕾娜：引航者，你看，这是我亲手设计的披萨，在保证配色与构图的同时，也兼顾了味道和口感…… |  |

|  |  |  |
| --- | --- | --- |
|  | 玛德蕾娜：哎，别不相信啊，我特地找妈妈做了特训，一定好吃！ |  |
|  | （正说着，玛德蕾娜切了一小块热乎乎的披萨递过来。） |  |

|  |  |  |
| --- | --- | --- |
|  | 玛德蕾娜：啊——怎么样？我没骗你吧，我总算做出既好看又好吃的披萨了！ |  |
|  | 玛德蕾娜：话说上一次的事情，我想了很久很久…… |  |
|  | （她凑近了过来，附耳小声说着，像是在倾诉只有我们两个人才能知道的秘密。） |  |
|  | 玛德蕾娜：这幅《田野物语Ⅳ》，作为我们之间牵绊的见证……引航者，我希望能够交给你来保管。 |  |
|  | 玛德蕾娜：我的很多作品，就像这幅画一样，诞生自山林，绿野，以及那些平凡的生活点滴。 |  |
|  | 玛德蕾娜：我想，这就是我的创作方式吧，在随处可见的平凡中取材，然后迸发灵感~！ |  |
|  | 引航者：你姐姐的事情……已经没关系了吗？ |  |
|  | 玛德蕾娜：嗯……用食物来比喻的话……在艺术这个领域，很多人会选择做一盘高贵的白松露料理…… |  |
|  | 玛德蕾娜：而我的话……大概只想做一块平价温暖的热披萨。 |  |
|  | 玛德蕾娜：我知道，姐姐要是听到这番话，肯定还是会说，“真是个幼稚的小鬼”，“脑袋里装满了不切实际”…… |  |
|  | 玛德蕾娜：她那种无聊大人式的发言……哼，我已经不在乎了，随她去吧~ |  |
|  | 玛德蕾娜：不过，要想做出一款独一无二的披萨，一定少不了新奇有趣的调料…… |  |
|  | 引航者：让我来做你的“调料”吧~让我来做你的“调料”吧~我会尽到一个顾问的职责。我会尽到一个顾问的职责。 |
|  | 玛德蕾娜：嗯，那就拜托你啦，顾问！ |  |
|  | 玛德蕾娜：嗯，那就拜托你啦，顾问！ |  |
|  | （话语声落下，玛德蕾娜看了看一旁偷笑的父母，害羞地不再言语。） |  |
|  | （在烛光的映衬下，她泛红的侧脸，还有蓬松可爱的居家服，披上了一抹柔暖的橘黄。） |  |
|  | （那是，属于她的色调。） |  |
|  | （之后又吃了好多块她为我而做的披萨，望着我们的《田野物语Ⅳ》……） |  |
|  | （心中泛起的温热弥久不散。） |  |
