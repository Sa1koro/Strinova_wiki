|  | （温暖晴朗的一日，奥黛丽的公寓内。） |  |
|  | （别扭的女孩似乎等候多时，即使满心期待，依照她的性格也不会直爽表露。） |  |
|  | 奥黛丽：……哼，你总算来了，但是迟到了五分钟！ |  |
|  | 引航者：抱歉抱歉……抱歉抱歉……只是五分钟而已……只是五分钟而已…… |  |
|  | 奥黛丽：态度还算及格吧，足够诚恳，知错就改总是好的。 |  |
|  | 奥黛丽：守时是十分重要的品格，是专业能力与礼仪规范的体现。 |  |
|  | 奥黛丽： ……不过念在你初犯，记得下不为例。 |  |
|  | （说话的间隙，奥黛丽身后放了一个超大号手提包，不知道里面装了什么东西。） |  |
|  | 引航者：那是什么？ |  |
|  | 奥黛丽：暂、且、保、密~ |  |
|  | （猜不透她的眼睛里到底藏着什么秘密，不知是先前提到的神秘琴谱，还是独角兽故事的答案。） |  |
|  | 奥黛丽：盟友，我们共处的这些日子里，一起喝了很多次咖啡呢。 |  |
|  | 奥黛丽：这种感觉有点像家族过去的茶话会，大家会选择一个宽敞明亮的房间畅聊整个下午。 |  |
|  | 奥黛丽：我记得餐架上至少要摆放三层咸甜口味的点心，品尝的顺序必须遵从由淡而重，由甜而咸。 |  |
|  | 奥黛丽：当然“茶”也是必不可少的…… |  |
|  | 奥黛丽：对了，还有音乐！ |  |
|  | （她绿色的眸子亮了起来，笑意粲然。） |  |
|  | 奥黛丽：没有音乐的茶话会始终是有缺憾的…… |  |
|  | 奥黛丽：盟友，和我到一个地方去吧！ |  |
|  | 奥黛丽：才、才不是特意邀请你呢，只是突然想出门散散步而已…… |  |

|  |  |  |
| --- | --- | --- |
|  | （一路带着那个手提包，她带我来到一处街心公园。） |  |
|  | （慵懒的下午，四周寂静无人，唯有喷溅出的水花如雨轻落。） |  |
|  | （她弯下腰打开包，取出了一把崭新的小提琴。） |  |
|  | 奥黛丽：事先说好，我只、只是想练习一下琴技…… |  |
|  | 引航者：你会拉小提琴吗？你会拉小提琴吗？你的琴技一定很出色吧！你的琴技一定很出色吧！ |
|  | 奥黛丽：那当然！音乐是每一位格罗夫成员的必修课，如果没有形成对艺术的兴趣，那样的人生是缺乏情调的。 |  |
|  | 奥黛丽：那当然！音乐是每一位格罗夫成员的必修课，如果没有形成对艺术的兴趣，那样的人生是缺乏情调的。 |  |
|  | 奥黛丽：上一次拉琴是在我很小的时候……从过去的家园，再到卡丘世界，这把琴陪伴了我多少年呢？ |  |
|  | 奥黛丽：我亲历过家族的纷争内乱，如今又肩负家主的重任，重振格罗夫，平日被繁忙琐碎挤占，无以抽身。 |  |
|  | 奥黛丽：我已经很久没有触碰过这把琴了，不知未来是否还有这样的机会…… |  |
|  | 奥黛丽：但至少在此时此刻——盟友，不介意在此刻听我演奏一曲吧？ |  |
|  | （女孩的声音渐渐变得温柔而郑重，话语刚落下，纯粹的琴音沿着震动的琴弓与琴弦翻飞而出。） |  |
|  | 奥黛丽：不要停下脚步，在森林之外，沙漠之外…… |  |
|  | （随着她的低吟，童话中最后的独角兽向着音符飞舞的方向一路奔跑。） |  |
|  | 奥黛丽：还有更加广阔的世界！ |  |
|  | （在那里，一个全新而又温暖的世界在等着它。） |  |
|  | （不知不觉间，夕阳已至，思绪顺着金色的光辉飘回到在少女周身。） |  |
|  | （似乎是少女内心的门扉逐渐开启，她亲手编织出的韵律也变得如阳光一般温暖。） |  |
|  | （开阔的广场上除了我们两个人，似乎还有一只寻觅同伴的独角兽。） |  |
|  | 奥黛丽：盟友，我只对我的家人演奏过这支曲子…… |  |
|  | 奥黛丽：契约已定，我希望我们长久保持现有的盟友关系，但是…… |  |
|  | 奥黛丽：在某些时候，同样佩戴独角兽勋章的你，对我而言，也宛若家人一般…… |  |
|  | （少女若有若无的声音融入了琴音之中，一时之间无法确定她是否开口说过这些话语。） |  |
|  | （但是，她外表那层坚硬的、用来保护自己的外壳已然褪去。） |  |
|  | （那只孤独的独角兽似乎消失了，眼前只有一位专注演奏的少女。） |  |
|  | （演奏结束时，夜幕悄然降临。） |  |
