|  | 米雪儿： 要的就是这股神秘感！待会儿到了你就知道了！ |  |

| --- | --- | --- |
|  | （俏皮的少女牵着我的手，雀跃着走进了一家温馨舒适的咖啡厅，店内休憩着慵懒的猫咪。） |  |
|  | 米雪儿：嘿嘿，这里就是我的秘密基地啦！—— |  |
|  | 米雪儿：这里是整个埃利蒙德唯一与NO.1系列联名的猫咖店，是NO.1系列粉丝线下聚会的首选之地！ |  |
|  | 米雪儿：哎呀呀，好痒好痒…… |  |
|  | （几只俏皮的猫咪不请自来，任性地在米雪儿四周泼皮打闹。） |  |
|  | （这些猫咪似乎每一只都和她很熟悉。被毛球包裹的少女完全放下了她的狡黠与神秘。） |  |
|  | 米雪儿：看着这些小家伙，我忽然想起了我家里的那两个孩子，火力大喵和喵喵卫士！ |  |
|  | 引航者：它们的名字好像有点特别…… |  |
|  | 米雪儿：你注意到了啊？《NO.1的正义英雄》的两位主角也叫火力大喵和喵喵卫士。但实际上，和这款游戏最有渊源的是——我的搜查官老爸，搜查科的一线英雄。 |  |
|  | 米雪儿：在来到卡丘世界之前，我的父亲就长年坚守前线，他是作为英雄被邀请到欧泊的。 |  |
|  | 米雪儿：我是在某次搜集攻略时无意中得知的，原来这款游戏是根据我父亲过去的英雄事迹改编的！其中，斩龙少年“火力大喵”的原型就是他！ |  |
|  | 引航者：原来是这样！原来是这样！你的父亲是一位英雄！你的父亲是一位英雄！ |  |
|  | 米雪儿：在此之前，我只是把父亲当作是我的游戏伙伴……在我小的时候，父亲平时很忙，但一有空了就常常带着我和机器猫们一起体验游戏…… |  |
|  | 米雪儿：对，他一直都是。 |  |
|  | 米雪儿：在此之前，我只是把父亲当作是我的游戏伙伴……在我小的时候，父亲平时很忙，但一有空了就常常带着我和机器猫们一起体验游戏…… |  |
|  | 米雪儿：他就像游戏里的“大喵”一样，手持巨剑，总是走在我前面，而我是那只拿着盾牌的“小喵”，安全地躲在他的身后。 |  |
|  | 米雪儿：后来父亲不幸染上了崩溃症，就再也没有人陪我一起玩游戏了…… |  |
|  | 米雪儿：不知不觉，我从游戏中学会了玩家思维，甚至直接代入了我的工作中……也因此我变得和别人不一样，总是遭遇同事排挤或上级训斥。 |  |
|  | 米雪儿：我原先一直在困惑，到底是做一名酷酷的玩家？还是做一名规矩的搜查官？ |  |
|  | 引航者：你现在有答案了吗？ |  |
|  | 米雪儿：嗯，我有了一个属于自己的答案……这个答案，我只想对你一人诉说。 |  |
|  | （此时，毛茸茸、圆滚滚的毛球们无一不紧挨着我们，反复在我们之间穿梭，央求抚摸与拥抱。） |  |
|  | 米雪儿：伙伴，这些猫咪也很喜欢你喔~它们把你当作猫群中的一份子了！ |  |
|  | 米雪儿：现在的我已经不再孤单一人了呢，我遇见了引航者，我有了新的游戏伙伴！ |  |
|  | 米雪儿：我发现，无论是作为玩家，还是搜查官，二者并不矛盾，无论哪一面，都是专属于我的特质。 |  |
|  | 米雪儿：无论哪一面，我都不想轻易放弃呢，可能这就是我，一名独一无二的超级玩家搜查官！ |  |
|  | 米雪儿：说出来可能有点难为情……我也希望能像英雄老爸那样成为游戏主角的原型。 |  |
|  | 米雪儿：但是，仅有我一个人是不够的…… |  |
|  | 米雪儿：毕竟主角也是需要同伴的嘛，对吧，我最好的游戏伙伴？ |  |
|  | 引航者：让我来做你的“大喵”吧！让我来做你的“大喵”吧！你就是那只“小喵”？你就是那只“小喵”？ |  |
|  | 米雪儿：哎嘿嘿……我们之间的默契真是心照不宣啊~ |  |
|  | 米雪儿：哎嘿嘿……我们之间的默契真是心照不宣啊~ |  |
|  | 米雪儿：咳咳，现在我的心愿要稍稍修订一下，我希望我们两个都能成为未来续作的原型…… |  |
|  | 米雪儿：决定了！下一代《NO.1的正义英雄》的主角就是了不起的引航者和了不起的搜查官！ |  |
